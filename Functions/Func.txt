What is a Function in JavaScript?

A function is a reusable block of code that performs a specific task when it is called (invoked).

Think of a function like a machine:

Input → Data goes in
Process → Work is done
Output → Result comes out

Syntax
function greet() {
    console.log("Hello World");
}
Calling a Function
greet();

Output:

Hello World


Function with Parameters

Parameters are values passed into a function.

function greet(name) {
    console.log("Hello " + name);
}

greet("Yashodip");

Output:
Hello Yashodip

Function with Return Value
function add(a, b) {
    return a + b;
}

let result = add(10, 20);
console.log(result);

Output:

30
Why Use Functions?
Without Function
console.log(10 + 20);
console.log(30 + 40);
console.log(50 + 60);
With Function
function add(a, b) {
    return a + b;
}

console.log(add(10, 20));
console.log(add(30, 40));
console.log(add(50, 60));

Benefits:

Reusability
Cleaner code
Easy maintenance
Less repetition (DRY Principle)
Types of Functions in JavaScript
1. Function Declaration
function sayHello() {
    console.log("Hello");
}
2. Function Expression
const sayHello = function() {
    console.log("Hello");
};
3. Arrow Function
const sayHello = () => {
    console.log("Hello");
};

Short form:

const add = (a, b) => a + b;
4. Anonymous Function

Function without a name.

setTimeout(function() {
    console.log("Executed");
}, 1000);
5. Immediately Invoked Function Expression (IIFE)
(function() {
    console.log("I run immediately");
})();

Real-Life Example
function makeTea(sugar, milk) {
    return `Tea with ${sugar} spoon sugar and ${milk} ml milk`;
}

console.log(makeTea(2, 100));

Output:

Tea with 2 spoon sugar and 100 ml milk
Definition for Interview

A function is a reusable block of code designed to perform a specific task. It can accept inputs (parameters), process them, and return an output. Functions help make code modular, reusable, and maintainable.
